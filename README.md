# Secure Password Manager (Qt + C++)

A native Windows password manager built using:
- Qt 6.8 Widgets
- C++17
- PostgreSQL
- CMake
- Visual Studio 2022

## Build
1. Install Qt 6.8.3 (MSVC 64-bit)
2. Install PostgreSQL
3. Open project folder in Visual Studio
4. Configure CMake
5. Build and run

## Notes
This project focuses on security, clean architecture, and maintainability.
